# QuickClip —— 网页图片「复制即收、右键快存」小工具

把网页里的图片复制后，到任意文件夹里右键一次，图片就自动保存进去了。支持连续复制多张、一次性批量保存。

<img src="./images/PixPin_20261017_143941.gif" width="850">

## 特点

- 零依赖：只用 Windows 自带的 PowerShell，不需要安装任何第三方软件
- 免管理员：只改动当前用户设置（HKCU），安全、可随时卸载
- 静默保存：保存过程不弹窗、不打断
- 批量命名：多张图片自动按 `图片_时间戳-01.png`、`-02.png`……编号

## 它能帮你做到的事

1. 网页看中一张图 → 右键「复制图片」→ 到你的文件夹 → 右键「保存收集的图片到此处」→ 完成
2. 想连续收藏多张 → 依次复制 → 最后在一个文件夹里右键一次 → 几张图一次性全部落盘

## 原理（一句话）

Windows 剪贴板一次只能放一张图。本工具用一个「后台收集器」把你每次复制的图先缓存到本地待存区，等你右键保存时再一次性导出到你选中的文件夹。

## 安装（只需一次，双击完成）

1. 打开本项目文件夹（QuickClip 所在目录）
2. 双击 **安装.bat**
3. 等待出现「安装完成」字样即可

> 说明：安装时也会把「后台收集器」设为开机自启。装完后建议**注销重登一次**即可正常使用。

## 每次开机后：启动后台收集器

后台收集器负责记录你复制的每一张图片，必须先运行它才能用。

- 安装后它会**开机自动运行**，一般无需手动操作。
- 若开机后发现右键没反应，双击 **启动.bat** 即可手动启动（后台运行，无窗口）。

## 使用方法

1. 在浏览器里，对喜欢的图片「右键 → 复制图片」
2. （可选）继续复制更多张
3. 打开（或定位到）你要保存的文件夹，在文件夹**空白处右键**（或在上一层**右键某个文件夹本身**），选择「**保存收集的图片到此处**」
4. 图片已静默保存到该文件夹，名字形如 `图片_20261017_143025-01.png`

补充：

- 不打开文件夹也能存：直接在上一层右键目标文件夹即可。
- 保存成功后，待存区和剪贴板都会自动清空，不会重复保存同一张。

## 常见问题

- **Win11 右键看不见菜单**：新版右键菜单会把自定义项折叠，右键后按住 `Shift`，或点菜单底部的「显示更多选项」即可看到。
- **复制了却没保存**：先确认「后台收集器」在运行——双击 **启动.bat** 再试。
- **菜单一直没出现**：新开一个资源管理器窗口，或注销重登一次。
- **想改保存目录**：本工具是「右键哪个文件夹就存到哪」，无需固定目录；若想改命名格式，可编辑 `save-all.ps1` 里含 `图片_` 的那一行。

## 卸载

依次执行下面两行即可恢复原样：

```powershell
.\uninstall-menu.ps1
.\uninstall-collector.ps1
```

分别对应「移除右键菜单」和「移除后台收集器」。

## 文件说明

| 文件 | 作用 |
|------|------|
| `安装.bat` | 双击执行一键安装（推荐入口） |
| `启动.bat` | 双击手动启动后台收集器 |
| `install-menu.ps1` | 安装「右键菜单」 |
| `install-collector.ps1` | 安装「后台收集器」并设为开机自启 |
| `collector.ps1` | 收集器本体（后台常驻，勿手动关闭） |
| `save-all.ps1` | 批量保存本体（由右键菜单自动调用） |
| `uninstall-menu.ps1` | 卸载右键菜单 |
| `uninstall-collector.ps1` | 卸载收集器 |
| `save-image.ps1` / `install.ps1` | 旧版「单张直存 / 热键」方案，备用 |
